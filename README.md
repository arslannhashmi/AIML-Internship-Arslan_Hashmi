# Part II — SkillForge AI capstone

## From notebook exercises to a product system

SkillForge AI turns a PDF resume into a structured career trajectory:

<pre>Resume PDF  →  skill profile  →  career ranking  →  proficiency gaps  →  learning path</pre>

The capstone extends the internship arc with PDF parsing, canonical skill normalization, importance-weighted career matching, explicit gap arithmetic, a NetworkX prerequisite graph, FastAPI routes, and a static browser dashboard.

### SkillForge AI highlights

- **Deterministic decisions:** the code makes all live ranking and roadmap decisions.
- **Explainable output:** the API returns structured records rather than opaque recommendations.
- **Graph-aware learning:** unfinished skills are ordered around prerequisites.
- **Live product surface:** a deployed FastAPI application visualizes match, gaps, and trajectory.
- **Professional documentation:** architecture, API, evaluation, screenshots, and final DOCX report are included.

- The internship notebooks are educational implementations and controlled experiments.
